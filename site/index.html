How it works

  1. Make the stamp

    Place shapes on a block and choose its outline and surface texture.

  2. Print the pattern

    Set it in a grid, half-drop, brick or honeycomb. Every print lands a little differently.

  3. Export it

    Save as PNG, JPG or SVG, or as a seamless repeat tile.

Coming next

  • Colourways

    Keep several colour versions of one design in the same project, see them side by side and export them all at once.

  • Print size

    Set the size in inches or centimetres at 150 or 300 DPI, so a tile arrives at the right size for fabric and wallpaper printers.

  • Separations

    Export one black-and-white plate for each ink or stamp, for carving, screen printing or 3D-printing real stamps.

  • Mockups

    Place the pattern on fabric, a pillow, a wall or a book cover for shop listings and client previews.
