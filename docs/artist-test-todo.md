# Artist test, Oct 27 2026: what was seen and what to fix

Source: the owner's rough notes from watching one artist use the app. Raw notes grouped; the order is a suggestion until the owner approves it. Features he has defined are marked Defined; the rest wait for his word.

## What she did (observations, not tasks)
- Opened Shapes first (the first button on the element bar). Opened Text styles expecting fonts (mistook one for the other).
- Collected many shapes for an overall theme and placed them as a list on the canvas, to reference later while building the image.
- Tilted the waves on the top row by hand, one by one.
- Used only text and shapes. No stamps, patterns or sheets (besides the default Background).
- The only frustration, and the number one cause of it, was element selection mistakes.

## 1. Selection (the one frustration; do first)
- [ ] A click on two overlapping elements sometimes selects both: a very short drag starts a selection box. Make the drag distance before a box starts larger.
- [ ] Overlapping elements: the one higher in the Elements list wins the click.
- [ ] A text element is selected only when the text itself is touched (not its box).
- [ ] With an element selected, a click on the empty space around the canvas deselects it.
- [ ] Lock an element so a click on the canvas cannot select or move it (on the bar; check what the Elements list lock already does).
- [ ] Hold Shift while dragging an element to switch smart guides off.

## 2. Placing and copying
- [ ] Paste near the bottom of the canvas lands off the canvas: clamp pasted elements to the canvas.
- [ ] Placing many times from a selected element. Defined (owner, Oct 27 2026): picking a shape in the library already lets you click to place it many times; the same is wanted for an element you have selected: a button on its panel makes a copy that ghosts on the pointer, and each click places one (like 2.54.3).
- [ ] A Pattern cannot get smaller than one piece of its smallest source.
- [ ] Idea from her reference list: a way to keep reference shapes off the final image (hidden layer, or a scratch area). Not asked for; discuss.
- [ ] Idea from tilting the waves by hand: rotating many selected elements at once, or by a typed angle. Not asked for; discuss.

## 3. Text
- [ ] Bold, italic and the other style options for text.
- [ ] Text styles was mistaken for fonts: look at the name and where fonts are chosen.

## 4. Colour
- [ ] A Done button on the colour maker or selector: after a custom colour is made the panel stays open.
- [ ] A Highlight colour in Settings, next to Accent. Defined (owner, Oct 27 2026): used for the smart alignment guides and for the selection box drawn by dragging.

## 5. Shapes
- [ ] Import button on the Shapes list: its words overlap once pressed.
- [ ] Crop in the shape import window. Defined (owner, Oct 27 2026): Shapes > Import turns a picture into a one-colour shape and the window has a Threshold control; a crop selection is active there, beside the threshold. No erase.
- [ ] Shape menus are a little confusing: look at what she hesitated on.
- [ ] Choosing a stamp shape: the transparency squares are tiny for the rectangle and much larger for all other shapes. Make them one size.

## 6. Panels
- [ ] Each panel tab can be closed.

## 7. Look
- [ ] Film grain looks bad: redo it.
- [ ] Gradients. Owner, Oct 27 2026: a system like the Sheet, which is a solid fill that takes effects: linear and radial gradients that effects can be applied to. His question: add gradient settings to the Sheet? Proposal, to confirm when we reach it: the Sheet gets a Fill choice (Solid, Linear, Radial) with its colours and angle or centre, so every effect already works on it; a separate Gradient element only if a gradient must sit above other elements.

## Text overhaul (release 3)
The owner wants to overhaul text and will give more for release 3 when we get there: ask him then. Bold, italic and the Text styles naming (section 3) wait for that.

## Unfinished note
The last note stops mid-sentence: "Say there are 100 elements in the element list, so the list is super full and". Ask the owner how it ends (probably a full Elements list being hard to use).

## Suggested order
1. Selection (section 1), one release: it is the only thing that frustrated her.
2. Paste clamp, Pattern minimum, Done button, Import overlap, transparency squares, tab close (small fixes), one release.
3. Highlight colour, copy-and-place and import crop (all defined now).
4. Film grain, then gradients (confirm the Sheet fill idea first).
5. Release 3: the text overhaul (ask the owner).
